# Support

Use GitHub issues for public support:

- bug reports
- feature requests
- unclear docs
- install or usage problems

Please include the filemap version, Node.js version, operating system, command you ran, and the smallest output that shows the problem. Redact private paths, private source names, overview text, and any secret-looking values before posting.

For security reports, do not open a public issue. Follow `SECURITY.md`.
